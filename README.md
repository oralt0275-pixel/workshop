# Сделки брокерского счёта в тенге

Страница `index.html` пересчитывает операции брокерского счёта из долларов США в тенге по официальному курсу Национального банка РК на дату каждой операции.

## Как пользоваться

1. Откройте `index.html` в браузере (двойной щелчок по файлу). Всё считается прямо в браузере, файлы никуда не отправляются.
2. Загрузите выписку транзакций (CSV или Excel), например выгрузку Charles Schwab.
3. Загрузите архив курсов USD с сайта nationalbank.kz (CSV или Excel со столбцами даты и курса).
4. Проверьте, что столбцы определились верно (дата, вид операции, сумма, курс). При необходимости выберите их вручную.
5. Скачайте результат в Excel/CSV или скопируйте таблицу.

## Что добавляется к выписке

| Столбец | Содержимое |
|---|---|
| Дата курса | дата, на которую взят курс; стоит сразу после даты операции |
| Ценная бумага | тикер из столбца Symbol, а если он пуст — из скобок в описании, например «QUALIFIED DIVIDEND (RIO)» |
| Курс USD/KZT (НБ РК) | курс на дату операции |
| Сумма, KZT | сумма операции × курс, округлено до тиына |

Вид операции показывается так, как он записан в файле транзакций (например, «Qual Div Reinvest», «NRA Tax Adj»). Цвет метки показывает группу: доходы, налоги и комиссии, покупки, продажи.

Правило выбора курса настраивается: строго на дату операции, на дату операции или последнюю предыдущую (если на дату курса нет), либо на предыдущую дату.

Итоги по каждому виду операции из выписки показаны в долларах и тенге; щелчок по виду операции фильтрует таблицу.

Таблицу можно сортировать по любому столбцу, в том числе по виду операции и ценной бумаге: нажмите на заголовок, повторное нажатие меняет направление. Выгрузка в Excel/CSV идёт в том же порядке.
